출생연도 변환 확정판

1. Windows PC에 Python 3.12를 설치합니다(Python Launcher 포함).
2. ZIP 전체를 압축 해제합니다.
3. HWPX_Lite 폴더에서 build_lite.bat을 실행합니다. 최초 빌드는 인터넷이 필요합니다.
4. 완료되면 dist-lite 폴더의 HWPX_Lite.exe를 실행합니다.
5. 파일 선택 → 사업장명 확인 → 변환하여 새 파일로 저장 → 한글에서 열어 확인합니다.

주민번호는 출생연도만 남기며 제목행은 '출생연도'입니다. 전체 삭제 선택은 제거했습니다.
예: 900101-1 → 1990년. 세기를 판별할 수 없는 값은 추측하지 않고 비웁니다.
표지·Disclaimer 교체 및 기존 목차 삭제는 기본 선택되어 있습니다.
기존 파일을 덮어쓰지 않으므로 새 저장 이름을 지정하세요.

테스트 9개 통과. Windows 빌드·한글 페이지 배치는 사용자 PC에서 확인이 필요합니다.
빌드 실패 시 오류가 표시된 창의 마지막 부분을 보내주세요.
