HWPX 공개본 비식별 변환기 (초벌 처리용)
==========================================
파이썬 설치 필요 없음. 이 폴더를 통째로 복사해서 쓰면 됩니다.
(HWPX_Redactor.exe 와 _internal 폴더는 항상 함께 있어야 합니다)

[방법 1] 파일 끌어놓기
  .hwp / .hwpx 파일(여러 개 가능)을 HWPX_Redactor.exe 아이콘 위에 끌어다 놓기
  → output 폴더에 "_공개본.hwpx" 생성

[방법 2] 폴더 감시 (여러 건 계속 처리할 때)
  HWPX_Redactor.exe 더블클릭 → 검은 창을 켜둔 채로
  input 폴더에 파일을 넣으면 자동 처리 (끝낼 때는 창 닫기)

폴더 설명 (처음 실행 시 자동 생성)
  input/   넣는 곳
  output/  공개본 결과
  done/    정상 처리된 원본 보관
  review/  ★ 자동탐지가 불확실했던 원본 — output 의 해당 공개본을 특히 꼼꼼히 확인
  log.txt  처리 기록

필요 조건
  - Windows
  - .hwp 파일을 넣으려면 한컴오피스 '한글'이 설치돼 있어야 함 (.hwpx 만 쓰면 불필요)
    · .hwp 변환 시 한글이 화면 없이 잠깐 실행됩니다 (첫 건은 30초~1분 소요)
    · 매번 "접근 허용" 창이 뜨면 '모두 허용' 선택

주의 — 이 프로그램은 초벌 처리용입니다. 반드시 사람이 최종 확인하세요.
  - 붙임 사진·도면 속 글자, 표 밖 제3자 이름, 특이한 서식은 놓칠 수 있습니다.
  - 회사명은 그림으로 바뀌어 있으니 한글에서 위치/크기를 눈으로 확인하세요.
  - 결과는 PC 밖으로 전송되지 않습니다 (완전 오프라인).

한컴 "변조 가능성" 경고가 뜨면: 한글 도구 > 환경설정 > 보안 > 문서 보안 설정 '낮음'
  → 열어서 다른 이름으로 저장하면 정상 파일이 됩니다.
